# Smart E-Mobility Hub

The **Smart E-Mobility Hub** is an Electric Mobility Coordination System designed for the VNU-HCM Urban Area. It serves to coordinate and manage electric mobility solutions efficiently within the university campus and surrounding urban areas, catering to the specific transportation needs of the VNU-HCM community.

**Team Size:** 6 members  
**Current Status:** Submission #1

## Submission Structure
- **Submission #1:** Requirements
- **Submission #2:** UI + Sequence + Activity diagrams
- **Submission #3:** Architecture + Class/Method design
- **Final:** Consolidated documentation + demonstration

## Repository Structure
- `docs/`: Project documentation and diagrams organized by submission phases.
- `src/`: Source code for the application.
- `tests/`: Automated tests and test cases.
- `assets/`: Project assets such as diagrams, images, and reference materials.
