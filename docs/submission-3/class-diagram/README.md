# Class diagram handoff

Create one editable PlantUML class diagram per module, named `01-hub-identity.puml` through `06-what-if.puml`, and export an image with the same stem. Use the class ownership in [task_assignment.md](../task_assignment.md). Show essential attributes and state, operation signatures, associations, and multiplicities. Refer to another module's class by name with `<<external>>` and its owner; do not redefine its operations.

Every operation shown must have a matching entry in the module's method catalogue. Keep this design aligned with the use-case scenarios and lifecycle diagrams from Submissions 1–2.
