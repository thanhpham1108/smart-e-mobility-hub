# Stakeholders, Roles and Expectations

| Stakeholder | Student | Operator |
|---|---|---|
| **Role** | End user uses Smart E-Mobility Hub network for vehicles transportation, parking and charging. | Operational user monitoring Smart E-Mobility Hub network and coordinating incidents, resources usage. |
| **Expectation** | Convenient access to available vehicles and hubs, accurate availability and battery information, reliable reservation, efficient parking and charging system. | Clear network visibility, real-time status information, handling operational incidents, charging scheduling, vehicles redistribution, optimal resources allocation. |
