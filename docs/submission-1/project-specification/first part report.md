1. **Context:**

In Ho Chi Minh City, people, especially students, increasingly use Metro Line 1 for transportation and may continue their journeys using shared electric motorcycles, electric bicycles, and other forms of electric mobility. This creates a need for a management system that not only manages electric vehicles but also coordinates parking capacity, charging resources, and mobility demand across different locations.

1. **Objective:**

The objective of this project is to design a software system called Smart E-Mobility Hub for managing and coordinating a network of electric mobility resources within the VNU-HCM Urban Area. The system aims to support users, drivers, staff, and operators in accessing and managing mobility resources efficiently.

1. **Scope:**

The scope of the Smart E-Mobility Hub system includes Hub and Identity Management, Vehicle Rental, Parking and Private EV Management, Operator Fleet and Incident Management, Smart Charging Scheduling, and What-if Simulation. The system focuses on managing and coordinating electric mobility resources within the VNU-HCM Urban Area, including vehicles, Mobility Hubs, parking spaces, and charging resources.

The project also includes defining the system's functional and non-functional requirements, developing the system use-case model, and implementing an MVP to demonstrate the core functionality of the Smart E-Mobility Hub system.
