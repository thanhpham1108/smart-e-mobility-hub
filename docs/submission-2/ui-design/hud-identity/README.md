# Smart E-Mobility Hub UI prototype
Responsive front-end prototype for Hub & Identity Management.

## Included screens
- Login / Registration (demo screen)
- Find a Mobility Hub (search, service filters, radius, illustrative map)
- View Hub Status (vehicles, parking capacity, charging points, battery levels, freshness timestamp)
- Supporting Personal Profile page for UC-H01

## Run
Extract the ZIP and open `index.html` in a modern browser. For browser geolocation behavior, run a local server from this folder (for example `python -m http.server 8000`) and visit `http://localhost:8000`.

## Demo-only notice
No backend, real authentication, database, live map, or sensor feed is connected. Hub and battery values are sample data. Never enter real credentials.
